VQA Review

Browse the Marker-CXR questions and answers overlaid on the images. Needs the Marker-CXR download from PhysioNet (vqa/, with vqa/review_manifest.json, and images/). Nothing is ever uploaded anywhere — both modes only read from this machine.

The three cohorts reuse image names (a single_marker PNG is a marker_free PNG with one marker pasted on), so images are looked up by <cohort folder>/p../p../s../file.png, and the top bar has a cohort dropdown.

Option A — local or mounted folders

Use this when this page's browser can see vqa/ and the images directly on disk (running on this machine, or they're mounted in, e.g. via SSHFS).

Option B — load from a server (SSH tunnel, no mount needed)

Copy this page into the Marker-CXR folder (the one that holds vqa/ and images/) and start a static server there:

cp review_vqa.html /path/to/Marker-CXR/
cd /path/to/Marker-CXR && python3 -m http.server 8000

On the same machine, browse to http://localhost:8000/review_vqa.html. On a remote machine:

ssh -L 8000:localhost:8000 user@remote-host

… then browse to http://localhost:8000/review_vqa.html and click below.
